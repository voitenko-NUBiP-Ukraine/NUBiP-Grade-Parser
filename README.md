Програма Grade Report Parser створена для автоматичного формування журналів оцінок у форматах .txt та Excel безпосередньо з цифрового порталу E-Learn НУБіП.

Інструкція з використання

1. Завантаження програми
Перейдіть у розділ «Releases» та завантажте актуальну версію файлу GradeParser.exe на свій ПК.
2. Збереження сторінки журналу
Відкрийте сторінку потрібного журналу оцінок у браузері. Натисніть праву кнопку миші, оберіть пункт «Зберегти сторінку як...» та вкажіть тип файлу: «Веб-сторінка повністю» або «Веб-сторінка, один файл».
3. Обробка файлу
Запустіть GradeParser.exe, натисніть кнопку «Select files...» та оберіть збережену раніше сторінку.
Після завершення обробки програма автоматично збере всі дані та збереже звіти у форматах .txt та Excel у вказану вами папку.
