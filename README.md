Програма Grade Report Parser була створена для формування архівів в форматі .txt та Excel журналів оцінок з цифрового порталу E-Learn НУБіП
Для її використання завантажте актуальну версію GradeParser.exe з розділу «Releases» на свій ПК
Після цього Вам необхідно зайти на сторінку необхідного журналу оцінок та натиснути праву кнопку миші, обрати пункт «Зберегти сторінку як» -> «Зберегти сторінку одним файлом»/«Зберегти сторінку повністю»
Запустіть GradeParser.exe та натисність «Select files...» обравши збережений результат з пункту вище.
Якщо Ви все виконали правильно, програма автоматично збере та збереже усі дані зі сторінки у форматах .txt та Excel
